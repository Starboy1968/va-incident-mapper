# Security and privacy policy

## Reporting a problem

Open a private security advisory on the GitHub repository (Security tab, Report a vulnerability). Do not post details publicly. Include steps to reproduce using fictional data.

Examples that count: any way the pages could send data off the device, store personal data in the browser, or write contact details to a file without the opt-in; a way to alter the hash-chained log without `verify` failing.

## Out of scope

- Whether a statute applies to a given situation (open a normal issue to correct the data).
- Anything that needs the person's device or browser to already be compromised.

## If you are a victim

This repository cannot help in an emergency. Call 911. National Domestic Violence Hotline: 1-800-799-7233. Cyber Civil Rights Initiative: 844-878-2274.
