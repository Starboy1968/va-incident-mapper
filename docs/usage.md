# Usage guide

Pick the tool that fits the person and the moment.

| I want to... | Use | Guide |
|---|---|---|
| Log incidents as they happen and export reports | `web/logger.html` | [logger.md](logger.md) |
| Be walked through it in plain language, then send a report | `web/intake.html` | [intake.md](intake.md) |
| Keep a tamper-evident log, analyze messages, script it | `va-incident-mapper` CLI | [cli.md](cli.md) |

All three share the same data tables and the same privacy rule: personal information is exported by the person who typed it, never stored by the tool. File layouts are in [file-formats.md](file-formats.md).
